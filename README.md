## 🚀 Featured Projects

### 📱 [Ascend — Screen-Time Manager](https://github.com/AnsariUsaid/Ascend) · [Google Play](https://play.google.com/store/apps/details?id=me.ansariusaid.ascend) · [Site](https://ascend.ansariusaid.me)
**Live on the Google Play Store** — a 17-screen Android app shipped as a paid client engagement. Replaces hard app-blocks with escalating math, trivia, logic, and typing challenges that users clear to earn timed grace periods. A custom Kotlin native module (Expo Modules API) bridges Android `UsageStatsManager`, `PackageManager`, and overlay APIs for per-app usage tracking on a reboot-surviving foreground service hardened for OEM battery optimization.  
**Tech:** React Native · Expo · TypeScript · Kotlin · EAS Build · Google Play Console

### 💼 [SalesFlow CRM](https://github.com/AnsariUsaid/salesflow-CRM)
Full-stack CRM for automobile parts sales with role-based access control, order lifecycle tracking, and procurement management.  
**Tech:** Next.js · TypeScript · GraphQL · Apollo Server · Prisma ORM · PostgreSQL · Authorize.net · Clerk Auth · Tailwind CSS

### 🧠 [HinglishSarc — Emotion Trajectory Sarcasm Detection](https://github.com/AnsariUsaid/HinglishSarc-Emotion-Trajectory)
Research project on sarcasm detection in Hindi-English code-mixed social media text. Dual-branch IndicBERT + BiLSTM model achieving **81%+ F1-score** on ~65K samples — 6% absolute improvement over mBERT baseline.  
**Tech:** Python · PyTorch · IndicBERT · BiLSTM

### 🏗️ [Modern Data Warehouse — Medallion Architecture](https://github.com/AnsariUsaid/SQL-DataWareHouse)
SQL Server data warehouse using Bronze → Silver → Gold layer architecture for progressive data refinement, with ERP/CRM CSV integration.  
**Tech:** T-SQL · SQL Server · ETL Pipelines · Star Schema

### ☁️ [ScalSQL — Cloud Text-to-SQL](https://github.com/AnsariUsaid/ScalSQL)
Scalable cloud-based system that converts natural language queries into executable SQL, deployed on AWS with automatic scaling and load balancing.  
**Tech:** JavaScript · AWS

### 🎙️ [AI Interview Platform](https://github.com/AnsariUsaid/ai-interview-application)
Interview preparation platform with automated question generation, AI-driven resume parsing, and structured response analysis.  
**Tech:** React · TypeScript · FastAPI · Redux Toolkit · REST APIs

### 📚 [Education Portal](https://github.com/AnsariUsaid/Education_portal_using-s3)
Student/teacher dashboard for assignment management with AWS S3 file storage, JWT auth, and role-based access.  
**Tech:** FastAPI · React · TypeScript · AWS S3 · PostgreSQL

### ♟️ [ML Chess Engine](https://github.com/AnsariUsaid/ML_Chess_project)
Deep learning chess engine trained on real games to predict human-like moves using CNNs.  
**Tech:** Python · PyTorch · CNN
